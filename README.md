# Gesture
🖐Gesture — десктопное приложение с дизайном Material Design 3 (Dark) для бесконтактного управления компьютером с помощью жестов рук через веб-камеру.  Весь анализ видеопотока выполняется на 100% локально на процессоре вашего устройства (на базе OpenCV и MediaPipe Hands) — кадры с камеры никуда не отправляются и не сохраняются.

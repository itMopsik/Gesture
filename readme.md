# 🖐 Gesture

**Gesture** — десктопное приложение с дизайном **Material Design 3 (Dark)** для бесконтактного управления компьютером с помощью жестов рук через веб-камеру.

Весь анализ видеопотока выполняется **на 100% локально** на процессоре вашего устройства (на базе `OpenCV` и `MediaPipe Hands`) — кадры с камеры никуда не отправляются и не сохраняются.

---

## ✨ Возможности

* **Дизайн Material You (Material 3 Dark)** — скругленные карточки, тумблеры `M3Switch`, капсульные кнопки и плавный индикатор удержания жеста.
* **Запись собственных жестов с камеры («＋ Записать свой жест»)** — покажите любую комбинацию пальцев в камеру на 2 секунды, и программа обучится распознавать ваш жест в любой части кадра и на любом расстоянии от камеры.
* **Гибкая настройка действий для каждого жеста**:
  * 🌐 **Открыть сайт (URL)** — любая ссылка в браузере по умолчанию.
  * 🚀 **Запустить программу (`.exe`)** — калькулятор, блокнот, браузер, игра или любое приложение.
  * 🔊 **Включить звук (`.wav`)** — воспроизведение аудиофайла или системного сигнала.
  * 🎬 **Запустить видео** — открытие локального медиафайла или ролика на YouTube.
  * 📂 **Открыть файл или папку** — мгновенное открытие нужной директории в Проводнике.
  * 💻 **Выполнить команду** — запуск любого скрипта или команды `CMD / PowerShell`.
* **Выбор камеры по названию** — автоматическое определение подключенных веб-камер и виртуальных камер (например, OBS Virtual Camera).
* **Мгновенный запуск и надежное автосохранение** — камера инициализируется в фоновом потоке через `DirectShow + MJPG`, а все добавленные жесты и настройки автоматически сохраняются на диск.

## 🤟 Базовые жесты из коробки

| Жест | Описание | Действие по умолчанию |
| :--- | :--- | :--- |
| 👍 **Палец вверх** (`THUMBS_UP`) | Большой палец поднят вверх, остальные сжаты | Открыть `https://github.com` |
| ✌️ **Два пальца** (`PEACE`) | Указательный и средний пальцы («V») | Запустить Калькулятор (`calc.exe`) |
| 🤘 **Коза / Рок** (`ROCK`) | Указательный палец и мизинец подняты вверх | Открыть видео на YouTube |
| 🖐 **Открытая ладонь** (`OPEN_PALM`) | Все 5 пальцев раскрыты | Проиграть звуковой сигнал |
| ☝️ **Указательный вверх** (`POINT_UP`) | Поднят только указательный палец | Запустить Блокнот (`notepad.exe`) |
| 👌 **Жест ОК** (`OK_SIGN`) | Кольцо из большого и указательного пальцев | Открыть папку программы в Проводнике |
| 🤟 **Три пальца** (`THREE_FINGERS`) | Указательный, средний и безымянный пальцы | Открыть `https://google.com` |
| ✊ **Кулак** (`FIST`) | Все пальцы сжаты в кулак | Открыть `mspaint.exe` |

## 🛠 Стек технологий

* **Python 3.10+**
* **OpenCV (`opencv-python`)** — захват видеопотока с камеры (`DirectShow / MJPG`) и отрисовка.
* **MediaPipe (`mediapipe`)** — локальное распознавание 21 ключевой точки кисти в реальном времени.
* **Pillow (`pillow`) & Tkinter** — графический интерфейс в стиле Material Design 3.
